# Visual assets

`frontend/public/space/earth-day.png`: NASA/Goddard Space Flight Center Scientific Visualization Studio, **Blue Marble — A Seamless Image Mosaic of the Earth**. Reto Stockli (NASA/GSFC) and NASA Earth Observatory.

- Source: https://svs.gsfc.nasa.gov/2915/
- Original image: https://svs.gsfc.nasa.gov/vis/a000000/a002900/a002915/bluemarble-2048.png
- NASA SVS usage information: https://svs.gsfc.nasa.gov/help/

The landing Earth is a decorative projection of this historical mosaic. It is not live imagery or a cloud-removal result. Earth rendering uses Three.js / React Three Fiber; a Canvas 2D projection provides a WebGL fallback.

Map data carries provider attribution in the UI. Reference tiles: CARTO/OpenStreetMap, Esri World Imagery, and MapLibre terrain. Their acquisition dates differ from analysis rasters. Third-party data and service terms remain applicable; these services are not operated by SPACE EYE.
